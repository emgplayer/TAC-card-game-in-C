# TAC Card Game

A command-line implementation of the TAC card game developed in C as part of the Algorithms and Data Structures course at the School of Electrical Engineering, University of Belgrade.

## Features

* Implementation of the TAC card game using a standard 52-card deck.
* **Blum Blum Shub (BBS) algorithm** for pseudorandom number generation.
* Singly linked list implementation using `void*` to store generic data.
* Stack and queue operations for managing game piles.
* Manual reversal of a singly linked list.
* Interactive menu and game state display.

## Technologies

* C
* Dynamic memory allocation
* Pointers and generic data structures
* Singly linked lists
* Stacks and queues
* Pseudorandom number generation

## Purpose

The project focuses on applying fundamental data structures and algorithms in C, with particular emphasis on memory management, pointer manipulation, and implementing a pseudorandom number generator using the Blum Blum Shub algorithm.
